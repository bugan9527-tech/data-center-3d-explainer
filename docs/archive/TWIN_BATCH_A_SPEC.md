### 一个环境结论

`verify-responsive` 在 **dev server** 上会报 `Attempted to synchronously unmount a root while React was already rendering`（drei `Html` 在开发态双渲染下的根卸载竞态）。用“完全移除消防系统”和“还原全部改动”两轮对照实验确认：**该错误在真基线上同样出现**，与本次改动无关；同一套件在生产构建上全过。后续回归请对着 `npm.cmd run preview` 运行。
