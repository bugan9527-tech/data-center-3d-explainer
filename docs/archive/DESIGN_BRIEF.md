# 视觉方向

## 主题

像一件可操作的工程展品：模型为主体，边侧文字解释职责，底部时间线解释协作。
采用浅色工程教学风格，语义明确的路径颜色，不堆叠与任务无关的指标。

## 色彩与字体

背景 #F0F4F7、场景 #EAF0F4、面板 #FFFFFF、正文 #182D43、数据蓝 #2468DF、电力琥珀 #C58B18、冷空气青 #0C96AC。
中文采用 Microsoft YaHei UI / PingFang SC，设备编号与数字采用 Bahnschrift。

## 布局

顶部：工程名称与整体结构、工作分工、协作流程。
左侧：六个系统的精简文字导航；中央：大面积三维机房；右侧：可收起的职责与输入输出面板。
场景底部：六个镜头章节、路径开关、一次读取并处理文件的 11 个阶段及当前阶段讲解。
收起面板时场景扩宽，保留朝向和相对缩放。窄屏将导航排列为按钮网格，说明移至场景与流程下方。

## 交互

选择设备不自动旋转镜头；保留用户视角。点击章节或“查看位置”才平滑定位，并开启对应路径；拖动、滚轮或下一次定位可中断。复位返回当前层级默认视角，减少动态效果时直接定位。
进入服务器时推近选中柜并准备内部资源，目标绘制后才切换；返回恢复机房视角和状态。准备层不可聚焦，切换后卸载上一层画布。
流程只有主动播放后才自动推进；可暂停或直接选择步骤。
提供清晰焦点和文字选中状态，减少动态效果偏好下保持静态路径。

## 计算服务器内部

从计算机柜进入单台服务器，沿用浅色场景和两侧职责说明布局。以敞口托盘、散热片、竖直内存条、接口卡、金属电源和带叶片的风扇建立外形差异。蓝色选中框带勾选文字；当前步骤用描边和“参与本步”标记，底部步骤名称与解释补充数据方向。

侧栏改为六部件文字列表，右侧解释职责、配合与当前阶段工作；小屏幕将列表排为三列、说明移至下方。完整／展开视图和键盘视角操作位于模型下方，五步流程继续置于模型之后。返回机房恢复先前选择、视角及入口焦点。

网络／存储请求增量沿用原有风格，统一蓝框表示选择、金色表示参与本步；请求蓝、文件数据紫、结果绿。小画布隐藏浮动标注，保留静态箭头及完整文字设备列表。
