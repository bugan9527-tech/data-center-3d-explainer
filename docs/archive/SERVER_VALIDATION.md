# 计算服务器内部展示：验证记录

验证日期：2026-10-30。后续沉浸布局与镜头衔接也已完成，生产构建回归通过，见 [本阶段验证记录](IMMERSIVE_VALIDATION.md)。保留现有 React、Three.js、React Three Fiber、Drei 和 Vite 工程，未新增运行时依赖。没有新增故障排查、维修教学或性能监控。

## 完成范围

- 保留机房、六类系统、整体结构／工作分工／协作流程及原有路径开关。
- 可点击具体计算机柜，或用文字选择框选择 C01–C04，打开其中的 01 号服务器。
- 返回时保留机房系统、机柜、模式、路径开关、展开状态、镜头旋转和缩放；恢复入口焦点。机房播放在进入内部前暂停。
- 六个功能组可从实际网格或文字列表选择。三维选中描边不参与拾取，避免抢占真实部件的点击。说明包含名称、职责、协作部件、当前阶段工作。
- 完整视图隐藏顶盖；展开视图将装配分离；可复位、拖动、滚轮缩放，或用键盘操作显式视角按钮。
- 请求由网卡进入，CPU 执行程序，外部存储数据读入内存，CPU 使用内存数据完成处理，最后网卡返回结果。主板提供连接与电力分配；电源和风扇持续提供支撑。
- 单一进度驱动步骤和移动标记，暂停保留时间，手动选步暂停并重置该步进度，重新开始回到第一步并暂停，播放结束不循环。页面隐藏时自动暂停。
- 减少动态效果偏好实时响应系统设置变更：保留静态高亮和箭头，停止移动标记，无自动旋转镜头。

## 模型与资源

原创 Blender 脚本：`blender/source/generate_server.py`；可编辑文件：`blender/source/server-internal.blend`；导出：`public/models/server-internal.glb`。

GLB 实际统计：205,252 字节（约 200 KiB）、25 网格、10 材质、2,768 三角形，无贴图。保存机箱和六个功能装配根节点，装配内部按材质合并。渲染时复用缓存几何及材质变体；退出释放内部画布及临时高亮资源。进入与返回的准备阶段短暂持有两个按需画布，等目标绘制后切换并卸载上一层；切换后仅保留当前层级的画布。静止使用 `frameloop="demand"`，像素比限制在 1–1.5，无内部实时阴影贴图。

## 剩余限制

- 四个计算机柜共用同一教学服务器模型，仅展示各柜 01 号服务器；网卡、内存、电源、风扇均按功能装配组选择，没有单条内存、单颗芯片的细分层级。
- 完整视图为隐藏顶盖的观察视图；展开位移不是安装或维修指导。路径是逻辑方向，不是实际总线布线或电路波形。
- 不模拟指令执行、操作系统调度、DMA、缓存层级、网络协议时序、电源冗余切换或真实热流。
- 没有在 Ryzen 5 5600／RTX 4060 8GB／16GB RAM 上进行长时间 FPS、显存或内存基准；不承诺帧率。
- Vite 仍提示公共三维包约 1,027 kB（gzip 约 275 kB）超过 500 kB。机房和内部场景共享三维引擎，内部业务代码及 GLB 已分开懒加载。
- 当前 R3F 依赖创建时钟会产生 `THREE.Clock` 弃用警告；未屏蔽警告或擅自升级依赖。每次重新创建画布可能再次出现，不属于 console error。
- 已检查键盘与基础屏幕阅读器语义；没有进行完整屏幕阅读器、所有浏览器及所有移动设备的人工兼容性认证。

## 后续增量：与机房业务流程一致

服务器内部继续保留原有五阶段和六部件。`useServerWorkflow` 现委托两级共用的 `useWorkflow`，保留原有暂停、继续、手动选步、重新开始与后台暂停语义。机房的网络到达／CPU 执行／存储读取／结果整理／响应返回分别映射到内部对应阶段。

进入前冻结机房时钟，内部独立观察不会推进机房请求；返回后恢复机房暂停点并等待用户继续。完整说明显示在入口与内部界面。若查看 C02–C04，则明确提示业务示例固定运行于 C01，当前柜仅展示相同的教学结构。

两级共用请求蓝、文件数据紫、处理结果绿的图例。内部外部节点标注“经机房网络”，省略的网络层由机房级完整展示。最新生产回归与截图见 [请求流程实施与验证](REQUEST_FLOW_VALIDATION.md)。
