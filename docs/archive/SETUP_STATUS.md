## 已完成的验证

- npm run build 通过，三维模块按需加载。
- 原创 Blender 机柜导出为约 450 KiB GLB；enclosure、server_bank、rack_frame 层级检查通过。
- 浏览器实际显示八台机柜、基础设施和可切换工作路径。
- 六类系统选择与职责、输入输出、配合关系联动。
- 机柜内部结构展开与收起。
- 电力、冷空气路径显隐。
- 工作流程可以自动推进至结束，支持手动选择步骤。
- 播放后暂停，在超过一步时长后仍保持同一阶段。
- 展示模式支持键盘左右箭头切换。
- 在窄屏宽度约 392 px 下未出现横向页面溢出。
- 稳定标注 portal 后，重新加载及交互检查未再出现浏览器运行错误。
- 实际页面截图保存在 outputs/data-center-explainer.png。

## 已知提示与边界

- 三维引擎模块仍超过 Vite 默认 500 kB 提示阈值；已与文字界面拆成独立异步模块，后续按实测加载体验继续优化。
- 当前三维依赖仍产生一条 THREE.Clock 弃用警告，不影响当前显示和交互。
- 模型、设备数量和连接方式是教学用的简化示例，不是施工设计或精确物理仿真。
- 尚未进行 1080p 长时间帧率基准测试，不承诺具体 FPS。
- 原装机占位源文件保存在 work/archive/pc-assembly-starter.zip；当前项目目录沿用现有工作区位置。
