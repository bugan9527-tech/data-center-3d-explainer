# 工程定位与范围

## 目标

用可交互的三维模型解释一个数据中心工程各部分负责什么、接收和输出什么、如何相互协作。
主要受众是不熟悉机房结构的学习者。

## 核心内容

- 网络设备：连接与转发；柜内分业务、存储与管理三类网络平面。
- 计算服务器：执行应用与处理任务。
- 存储设备：持久保存与数据读写。
- 供电系统：双路市电 → ATS → UPS → 配电柜 → 母线 → 机柜 PDU → 设备电源，含室外柴油发电机作为备用。
- 制冷系统：架空地板送风、设备进风与吸热、热通道回风的基本回路。
- 监测系统：传感与设备状态采集，不用摄像头代表运行状态监测。
- 消防与安防：灭火剂钢瓶、报警控制器、声光、烟感、消防管路、门禁与摄像头。
- 备份与容灾：独立备份机柜（备份服务器、磁带库、备份存储），强调本地备份不等于异地容灾。

## 核心体验

看整体 → 选择系统 → 阅读职责和输入输出 → 展开机柜结构 → 播放协作过程。

当前流程以读取并处理一份云端文件为例，细分为 11 阶段，包含端口接收／转发／出口、计算、存储控制／读取／回传和响应返回。
供电与制冷不插入这 11 个步骤，而是作为持续支撑单独分步讲解（供电 6 步、制冷 7 步），并可与业务流程同时查看。
流程是教学简化，不能当成所有业务和所有机房的唯一架构。

## 场景预算

开发电脑：Ryzen 5 5600、RTX 4060 8GB、16GB RAM。
一个机房、9 台复用 GLB 机柜、两台制冷设备、UPS 与配电柜、室外电力平台、传感采集盒。
静止时按需渲染，像素比上限 1.5。场景没有外部纹理或在线模型依赖。
FPS 需要在目标浏览器和显示分辨率下实测，目前不承诺具体帧率。

## 边界

- 只讲正常工作原理与结构分工。故障／告警演示只改变局部提示、告警文案与消防管线高亮，不模拟故障判定、切换或处置流程。
- HUD 的在线率、CPU、内存、吞吐、温度、功率等读数是**明确标注的模拟值**，不连接任何实时接口；这是本项目最容易引起误解的一处，改动时不得删除"模拟"角标与"无实时接口"说明。
- 端口、连接、存储介质、电路与气流均为教学抽象，不模拟真实协议时序、指令调度、电路信号或流体场。
- 不做完整自动导览（可选方向），不做维修教学与性能监控。
