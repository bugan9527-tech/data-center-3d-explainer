# 批次 C 实施记录：备用电力与室外平台

状态：**已完成**（几何与链路）。施工期间出现过两套互相冲突的界面口径，已于 2026-11-03 拍板以数字孪生看板为准，决策过程保留在第六节作为记录。

## 一、决定与空间推导

需求书要求“备用发电机位于建筑外部，不得直接放在服务器机柜之间”。地板是 `[0,-.08,-.45]`、尺寸 `11.9 × 8.9`，也就是 `x ∈ [-5.95, 5.95]`、`z ∈ [-4.9, 4.0]`。所以“室外”只能是地板之外。

三个候选位置都被否掉：

- **后墙外**（`z < -4.83`）：后墙高 3.25、从 `y 2.4` 才开始淡出，2 m 高的机组会被整块挡住；而且总览相机在高处俯视，视线先撞墙。
- **左前**：已被消防钢瓶柜与入口门框占用（批次 A）。
- **右前方**（`z > 4.0`）：会把机组放进镜头前景，挡住存储区。

最终选 **右侧**：`x > 5.95`，紧邻现有进线箱与配电柜所在的一侧，电缆走最短，也不挡任何机柜。

## 三、供电链重画

`supportSystems.js` 的 `powerChain` 起点从进线箱改为 **ATS 输出**，前面补 4 个点跨过地板边缘：

```
[6.42,1.50,-3.92] → [6.02,1.66,-4.12] → [5.52,1.84,-4.36] → [5.02,1.96,-4.54] → [4.62,2.02,-4.63]
```

之后接原有路径（进线箱上方 → UPS → 配电柜 → 母线 → 机柜 PDU → 设备电源）。琥珀色流光因此从室外平台一路流进机房，这正是常态下真正的电流方向。

**发电机到 ATS 的那段线刻意做成静态。** 它只在市电中断时才带电，让它跟日常流动的琥珀色路径一起流动，等于告诉观众“发电机一直在供电”。这是本轮唯一一处主动加的工程语义。

`systems.js` 的供电系统文案同步改为：“市电与柴油发电机在 ATS 处汇合，由 ATS 选择其中一路送往 UPS……发电机与 ATS 放在机房外侧的平台，日常待机，只有市电中断时才接通”。

## 六、必须说明的冲突

本轮施工期间，另一个窗口把界面重构成了**数字孪生看板**：左侧“运行概览”（设备总数、在线率、CPU 42%、内存 64%、网络吞吐 1.72 Gbps、负载趋势图）、右侧“环境与能源”（机房平均温度 23.6 °C、当前总功率 38.6 kW）、顶部“运行正常／局部故障／告警处理中”状态演示、动效图层开关，以及深色 + Bloom 主题。这些读数带有“模拟数据”标注。

这**与本轮早先定下的口径相反**。此前的决策是“结构表达、不做数字、不做告警模拟”，依据是 README 原有的“不提供实时数据、仪表盘或虚构读数”与 `HANDOFF.md` 硬约束第一条；`docs/TWIN_UPGRADE_REVIEW.md` 的决策记录也是这么写的。

## 七、已知局限

- 发电机与 ATS 不可点击：点“供电系统”会直接打开 UPS 拆解，点发电机却弹 UPS 会让人困惑，所以整组按不可交互处理（与右前空地的道具同一处理方式）。
- 平台在地板右缘之外，窄屏下可能被右侧“环境与能源”面板压住一部分。
- 只有一路市电进线；双路进线与 UPS 双输入没有做，`README` 的范围限制里仍保留这条。

## 八、双路市电（同日补充，用户拍板"真做"）

初版只画一条进线，而 HUD 三种状态都写着"双路输入正常"——面板替场景说了它没有的话。选择不是改文案，而是把双路做出来。

- 后墙并排两个 `feed_panel`：[4.62, 1.0, -4.7]（A 路）与 [2.2, 1.0, -4.7]（B 路）。
- **A 路**：进线箱 → ATS（室外平台）→ UPS 主输入，即 `powerChain`。
- **B 路**：进线箱 → 直接到 UPS 旁路输入，新增 `powerChainB`，画得更细更淡（`width 1.8/2.0`、`opacity .38/.44`、流光 `size .2`），保证主路仍然先被读出来。
- 两路互不依赖：A 路失电由发电机接管，B 路失电不影响主路。UPS 因此真的有两条可用输入，"双路输入"这句话成立了。

口径同步：`upsNote` 三档改为 `A 路主用 · B 路旁路待机` / `A 路已切至发电机 · B 路旁路` / `旁路供电 · A 路待恢复`。

## 九、HUD 口径与总设备数

- `设备总数` 改为**派生**：`racks.length + POWER_UNITS.length + COOLING_UNITS`，当前 = 9 + 6 + 2 = **17**。以后加设备不会再有第三次数值过期。
- KPI 标签从"设备总数"改为"机柜与动力设备"，脚注写明"不含消防安防末端"——烟感、喷嘴、摄像头、门框、探头盒这类末端件是配件不是容量，计入会让数字失去意义。
- `冷却` 文案从 `2 / 2 机组` 改为 `2 台运行 · 无备用`：两台 CRAC 就是全部，没有 N+1，`2/2` 会被读成"冗余健康"。
